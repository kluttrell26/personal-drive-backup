Personal Drive Backup

This privately operated utility uses rclone to back up selected files from the owner's local storage to the owner's Google Drive account.

How it works

The owner authorizes Google Drive access through Google's OAuth consent screen. The backup process reads Drive file metadata to compare files and uploads selected local files to the owner's Drive. The current workflow copies files and refuses to overwrite changed destination files.

This website contains information only. It does not provide a login form, access the visitor's Google account, or run the backup utility. The utility is for the owner's personal use and is not offered as a public service.
