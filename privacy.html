Personal Drive Backup

Privacy policy

Last updated: October 22, 2026.

Personal Drive Backup is operated for the owner's personal use. It uses rclone to copy selected local files to the owner's Google Drive account.

Google account data and permissions

The utility requests Google Drive access through OAuth. The requested Drive permission permits reading, creating, modifying, and deleting Drive files. The current backup workflow uses file and folder metadata to identify the destination, compare files, and copy selected local files to Drive. It reads Drive storage quota during credential checks. The requested permission is broader than the operations performed by this workflow.

Use and storage

Google account data is used to authorize and operate the owner's backups. OAuth access and refresh tokens are stored in private configuration files on the owner's server. Configuration backups may retain previous tokens. Temporary authorization configurations are removed after use. Local operational logs may contain filenames, paths, transfer statistics, and error messages. The backed-up file contents are stored in the owner's Google Drive account.

Sharing

The operator does not sell Google user data, use it for advertising or model training, or intentionally share it with unrelated third parties. Backup files and API requests are transmitted to Google to provide the storage and authorization services the owner requests.

Control, retention, and deletion

The owner controls the server, configuration files, logs, and backup retention. Copies remain in Google Drive until the owner removes them. The owner can revoke this utility's authorization in Google Account settings and remove locally stored configurations and logs. Revoking authorization does not itself delete previously uploaded backups.

This informational website

These pages contain no application analytics, advertising scripts, forms, or application cookies. GitHub Pages hosts the pages and processes ordinary website request information under GitHub's privacy statement. Visiting this website does not grant the utility access to a visitor's Google account.

Contact

Questions can be raised through the project's public issue tracker. Do not post tokens, backup contents, or private account information.
